# CENT evaluation harness — frozen definition

This file is the comparison substrate. Its SHA-256 is stored in `harness.sha256` and referenced by
`run_sheet.json`. Any change to what is defined here voids every cached baseline number and requires
an amendment plus a rerun — it is never a quiet edit.

## Inputs

- Images: grayscale, cropped to the tight ink bounding box, padded to a square, resized to
  **64×64**, ink = 1.0, background = 0.0. Identical for every method and every metric.
- For trajectory metrics: points kept in the corpus coordinate system, resampled at uniform arc
  length to **64 points per stroke** before order matching.

## Metrics

1. **Legibility — CER.** A single frozen Chinese HTR checkpoint, used for all methods, never
   fine-tuned on generated data. CER = edit distance / reference length over the test character
   sequence. Reported per cell of the seen/unseen × character/writer grid.
2. **Stroke correctness — two statistics, both reported.**
   - `stroke_count_acc` = fraction of generated samples whose stroke count equals the lexicon count.
   - `soec` (stroke-order-equivalence-class distance): minimum normalised edit distance between the
     predicted stroke-type sequence and any order in the character's equivalence class, where the
     class is generated by a declared merge rule (two adjacent strokes merge when the pen-up
     displacement is below the corpus 5th-percentile inter-stroke gap and the turn angle is below
     20°). Primary statistic.
   - `soed` (raw canonical-order distance) reported alongside, never alone.
3. **Realism — FID.** Inception-v3 pool3 features, same preprocessing as above, computed per writer
   and averaged. Reference distribution = real images of the same characters by the same writers.
4. **Style fidelity — writer verification.** Frozen style encoder; same/different writer pairs,
   balanced, accuracy and EER.
5. **Entanglement — two frozen probes.** Content-probe accuracy on generated images (higher is
   better) and writer-probe accuracy (higher is better); a method that scores high on one and low on
   the other has entangled the factors.
6. **Human judgement.** Forced-choice real-vs-generated and same-writer questions, N ≥ 30 native
   readers, pre-registered question order, balanced randomisation, no method labels shown.

## Splits

Writer-disjoint. The gate reads only the **validation** subset (60 writers carved from the released
training partition, characters disjoint from the target set). The reported test partitions
(`CASIA-HWDB1.x` released test split; `ICDAR-2013` competition set) are evaluated **once**, in
Phase 4, after a gate PASS, and reported whatever they show.

## Aggregation and inference

- 3 seeds per configuration (`seeds: [0, 1, 2]`); report mean and 95% bootstrap CI over **test
  characters** (items), 10,000 resamples, not over pixels.
- Paired bootstrap against each baseline for the decision metric; Holm correction within the
  baseline family.
- No per-cell tuning on test. No test-time model selection.

## Frozen provenance

Every reported number must trace to `runs/<experiment_id>/results/` and a provider record. A number
without both is not reported.
